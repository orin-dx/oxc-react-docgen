4. Errors and fixes:
   - **Perf regression self-introduced and caught via benchmark, not guesswork**: naive `NamedTypeIndex::build()` rebuild on every `WatchSession::update_file()` call caused ~90% regression on the `incremental_update` criterion benchmark group. Diagnosed by reasoning that `self.global.rcu()`'s existing full-clone-per-edit cost was already accepted, but the NEW index rebuild was a SECOND full pass on top of it, not amortized like the one-shot `extract()` path. Fixed via true incremental patching (`Mutex<Arc<T>>` + `Arc::make_mut` + `remove_file`/`merge_file`), verified via re-running the benchmark (regression became a net −14% to −48% improvement) and the full test/snapshot suite.
   - **`lookup_type_alias`'s changed return semantics silently broke generic type-parameter registration** (would have compiled cleanly and failed silently): its "matched key" changed from the full flat `"file:name"` string to just the bare/qualified name, but `named.rs` and `substitute.rs` (specifically `apply_generic_args` and `generic_alias_with_structured_args`) still tried to look up `type_alias_params`/`type_aliases` using that value as if it were the old flat key. Caught by careful call-site tracing (not by a failing test — this was found via code review of every caller before it could regress), fixed by rerouting through the new `NamedTypeIndex::lookup_type_alias_params`/`lookup_type_alias_exact` methods and restructuring `apply_generic_args`'s signature.
