2. Key Technical Concepts:

- **oxc-react-docgen**: 10-100x faster drop-in for react-docgen-typescript using OXC (Rust) for parsing instead of tsc
- **RDT (react-docgen-typescript)**: The tool we're replacing; uses TypeScript Strada API (dropped in TS 7.0)
- **TypeScript 7.0 / tsgo**: Go rewrite of tsc; Strada API dropped; Corsa API (replacement) targets TS 7.1 ~Q1 2027
- **CollectedType**: AST extractor's intermediate representation (Named, Union, Intersection, Function, etc.)
- **CollectedTypeAlias**: Pick, Omit, Partial, Required, Union, Passthrough, etc.
- **PropType**: Resolver's output type (21 kinds: string, number, boolean, literalUnion, eventHandler, etc.)
- **ExtractionOutput**: Final output `{ components, enums, diagnostics, stats }`
- **ComponentEntry**: `{ displayName, filePath, description, props, inheritance, notableInherited, discriminantProp, composes, tags, methods }`
- **ResolvedChain**: Intermediate resolver structure `{ props, inheritance, composes, inherited_by_name, discriminant_prop }`
- **InheritedLayer**: Records HTML element inheritance `{ typeName, fileName, htmlElement, omitted }`
- **resolve_props_chain**: Main resolver entry point in `resolver/chain.rs`
- **validate harness**: `apps/validate/` with react-docgen-typescript, react-docgen, and our tool comparison
- **notableInherited**: Our approach to HTML attrs — surface 15-20 key attrs per element instead of RDT's 250-300 inline expansion
- **CVA/VariantProps semantics**: `| null` on variant props is intentional (null opts out of variant)
- **Corsa API**: Replacement for Strada in TS 7.1; needed for generic substitution, conditional type evaluation
