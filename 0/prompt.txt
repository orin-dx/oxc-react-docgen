2. Key Technical Concepts:

- **RDT output shape**: `ExtractionOutput { components, enums, diagnostics, stats }` → `ComponentEntry { displayName, filePath, description, props, inheritance, notableInherited, discriminantProp, composes, tags, methods }` → `ParsedProp { name, type, required, defaultValue, description, tags, parent, declarations }`
- **PropType tagged union**: 21 kinds — string, number, boolean, null, unknown, undefined, never, void, any, reactNode, cssProperties, elementType, sxProps, stringLiteral, numberLiteral, boolLiteral, union, intersection, array, tuple, object, named, eventHandler, ref, htmlAttributes, literalUnion, opaque
- **CollectedType → PropType**: AST extractor produces CollectedType; resolver pattern-matches to produce PropType
- **arg-index bug (FIXED)**: `interface.rs:77` always used `call.arguments.get(1)` for all recipe callees; only `cva(base, config)` puts config at index 1; `defineRecipe({config})`, `recipe({config})`, `tv({config})`, `defineSlotRecipe({config})` all put config at index 0
- **TSMethodSignature vs TSPropertySignature**: Two different AST member forms; only TSPropertySignature gives full type; TSMethodSignature hardcodes params as `vec![CollectedType::Raw("...")]`
- **Six fundamental gap patterns** (collapsed from 12 symptoms):
  1. Interface member form completeness (method sig, index sig, call sig)
  2. React namespace recognition (SVGAttributes, ComponentRef, HTMLProps, JSXElementConstructor, AriaAttributes)
  3. Transparent wrapper completeness (Readonly<T> → zero props)
  4. `typeof` expression resolution depth (`typeof Primitive.button` not resolved)
  5. Inline utility types in extends position (`extends Pick<T, K>` vs named `type X = Pick<T, K>; extends X`)
  6. Generic parameter substitution (_type_args always ignored)
- **TypeScript 7.0 / tsgo / Corsa API**:
  - TypeScript 7.0 RC landed June 18, 2026 (this week)
  - TypeScript 6.0 = final JavaScript-based tsc
  - Strada API (ts.createProgram, checker.getTypeAtLocation, etc.) COMPLETELY DROPPED in TS 7.0
  - react-docgen-typescript is broken under TS 7.0
  - Corsa API (replacement) targets TypeScript 7.1 — late 2026 or early 2027
  - OXC built `tsgolint` (subprocess IPC with typescript-go shims) as precedent
  - oxc-react-docgen is UNAFFECTED by TS 7.0 (uses OXC for parsing, not tsc)
- **What truly requires a type checker**: Only conditional types (already opaque), mapped types (already opaque), and multi-level generic propagation. The 6 fixable gaps are all structural.
- **DTS cache**: `node_modules/.cache/oxc-react-docgen/` using msgpack + atomic write, mtime+size keyed
- **recipe callee arg index**: CVA = index 1; everything else = index 0

4. Errors and Fixes:

- **`interface.rs` arg-index bug**: All recipe callees (defineRecipe, recipe, tv, defineSlotRecipe) were using `call.arguments.get(1)` but config is at index 0 for non-CVA callees. Fixed with `let arg_index = usize::from(callee_name == "cva");`. Panda snapshot now shows expanded variant props.

- **Avatar component description bug**: `Avatar.description = "Avatar diameter in pixels. @default 40"` — this is the `size` prop's description, not the component's. Root cause: `find_jsdoc` proximity scan finds the nearest preceding block comment (120-byte threshold). When no component-level JSDoc exists, it finds the last prop's JSDoc. Documented in coverage matrix but NOT yet fixed.

- **Pick<SourceInterface> in extends clause**: `interface X extends Pick<T, K>` goes through `classify_extends` → `ExtendsRef::SameFile { name: "Pick", type_args: [...] }` → `resolve_props_chain("Pick", type_args, ...)` → step 1 returns empty. The alias.rs Pick handler is never reached because it's only reachable from type_aliases map (top-level `type X = Pick<T, K>` form). Needs step 0.5 in chain.rs.

- **Accordion union-of-interfaces silent skip**: Component with `ForwardRefExoticComponent<InterfaceA | InterfaceB>` props is completely absent from output with no diagnostic. The resolver's component detection path doesn't handle union at root props level. Documented, not yet fixed.
